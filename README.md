## Описание
Программа читает из текстового файла сведения о книгах (фамилия автора,
название, год издания, количество экземпляров, цена), выводит список книг
задаваемого автора и их общую стоимость (сумма `количество × цена`), а также
находит самую старую книгу среди всех. Отчёт на экране и в выходном файле
совпадает. Данные хранятся в `struct Book` и коллекции `vector<Book>`.

## Входные данные
- С клавиатуры: путь входного файла, путь выходного файла, фамилия автора.
- Файл: одна книга на строку, 5 полей через `;`:
  `author;title;year;quantity;price`
- Символы ASCII, дробная часть через точку. Не более 100 записей,
  пустой файл допустим.
- Проверки: непустые автор и название, год 1450–2100, количество ≥ 0,
  цена ≥ 0, без посторонних символов после чисел. При ошибке —
  `ERROR line N` и завершение без частичного отчёта.

## Выходные данные
- Список книг автора (или `EMPTY`), число книг, суммарное количество
  экземпляров, общая стоимость.
- Самая старая книга (или `NONE` для пустого файла); при равных годах
  выбирается первая запись файла.

## Как запустить
Открыть проект в Visual Studio и запустить без отладки: Ctrl+F5.
Файл `input.txt` должен лежать в рабочей папке программы; для первого
запуска укажите абсолютный путь. Либо из консоли:
`g++ -std=c++17 -o lab7 Lab7.cpp` и `./lab7`.
